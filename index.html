FastAPI Webhook Delivery Platform

Self-hosted webhook delivery with PostgreSQL as the only durable queue — no Redis or Kafka to operate. Two decisions carry the design: workers hold lease-fenced claims over immutable accepted-work snapshots, so a stalled worker can never overwrite a peer’s progress; and signatures follow the Standard Webhooks spec and are cross-verified in CI by the official ecosystem library rather than by my own code. A reproducible one-million-delivery run completed with zero lost jobs. The published benchmarks also report the queue-age target the design missed — the number is public because it is honest, not because it flatters.

AgentOS — Durable Agent Workflow Control Plane

A control plane for durable, observable, human-in-the-loop LLM agent workflows: a DAG of agent steps over an append-only, hash-chained event log (PostgreSQL; SQLite locally). Two decisions: steps that declare effects — spend, external writes, code execution — suspend the run for approval before they execute, and the decision and who made it live in the log; and model providers are separate plugins the core never imports, a boundary import-linter enforces in CI. Chaos-tested on every pull request: a real worker is SIGKILLed after step 2 of 3 commits and a second worker finishes the run with exactly one committed completion per step. The boundary of that claim, stated plainly: fenced leases and idempotent transitions prevent duplicate committed completions; an external side effect performed just before a crash still depends on downstream idempotency or reconciliation.

Privacy-First Code Quality Analyzer

Offline static analysis for eight languages, on PyPI as cqa-analyzer: 68 rules, a 62-pattern architecture catalog, changed-line CI gates, SARIF. It never runs git or any subprocess, and scoring is recalibrated against a public 24-project corpus on every policy change. A stdlib MCP server adds a delegate mode where every rule states when it deliberately stays silent, each clause locked to a fixture. Known limit: the rules are lexical — a first run against Alibaba’s AACR-Bench review corpus matched none of its logic-level duplication comments.

CloudScale Backend

CQRS and event-sourcing service with a typed hexagonal core; SQLite and PostgreSQL adapters sit behind the same ports. Idempotent commands with transactional dedupe and a transactional outbox; consumer high availability through advisory-lock leader election, with SIGKILL failover measured at 0.27 s. Sustains 1,394 rps on the embedded (SQLite) tier with every security and observability control active; the PostgreSQL tier is ~850 rps per worker and scales horizontally. Limit stated in the repo: 30-day availability is a target, not a claim.

Wallet / P2P Transfer Service

FastAPI and PostgreSQL wallet built around three invariants — money is conserved, a retried transfer applies once, nobody moves another user’s money — each enforced on every mutation path: INSERT … ON CONFLICT DO NOTHING for race-free get-or-create, transaction-bound idempotency keys, and a fixed lock order so opposite-direction transfers cannot deadlock. Concurrency tests drain a balance from 30 parallel clients and prove overspend impossible.
